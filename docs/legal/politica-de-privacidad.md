# Política de privacidad — Tratohecho (borrador)

> **Borrador para revisión legal.** Ajustar con un abogado antes de publicar.

**La aplicación instalada** guarda toda la información (clientes, cotizaciones, catálogo, logo) en el computador del
usuario. No envía datos a nuestros servidores ni a terceros, no tiene telemetría y no requiere crear una cuenta.
Respecto de los datos personales de sus clientes, la empresa usuaria es la **responsable** del tratamiento
(Ley 21.719). La aplicación ofrece funciones para exportar y suprimir los datos de una persona cuando esta lo solicite.

**La demo pública** contiene únicamente datos ficticios. No ingreses datos reales: todo se borra cada hora.

**Al comprar** tratamos tu nombre, RUT, correo y datos de facturación solo para emitir el documento tributario, entregar
la licencia y prestar soporte. Los pagos los procesa la pasarela de pago; no almacenamos datos de tarjetas.

**Derechos:** puedes pedir acceso, rectificación, supresión, oposición y portabilidad de tus datos escribiendo a
[correo de contacto].
